# BGP 설계

ISP-1, ISP-2 내부의 eBGP 구성을 정리한 문서. 사이트(HQ, DC, BR1, BR2)와 Private Internet은 BGP 미사용. 링크 IP는 `docs/ip-mapping.md`, 포트는 `docs/port-mapping.md` 기준.

## 1. AS 구성

- ISP 라우터는 장비마다 개별 AS를 사용하는 eBGP 전용 구성이며 OSPF 없음.
- 사이트 AS(HQ 65001, DC 65002, BR1 65003, BR2 65004)는 사이트 식별용 번호이며 BGP 세션 없음. 사이트↔ISP 구간은 정적 경로와 OSPF 재분배(`docs/ospf-design.md` 6절).

|---|---|---|---|
| ISP-1 | ISP-1-PE-A | 65111 | 100.1.0.0/16 |
| ISP-1 | ISP-1-P1 | 65112 | 100.1.0.0/16 |
| ISP-1 | ISP-1-P2 | 65113 | 100.1.0.0/16 |
| ISP-1 | ISP-1-PE-B | 65114 | 100.1.0.0/16 |
| ISP-2 | ISP-2-PE-A | 65121 | 100.2.0.0/16 |
| ISP-2 | ISP-2-P1 | 65122 | 100.2.0.0/16 |
| ISP-2 | ISP-2-P2 | 65123 | 100.2.0.0/16 |
| ISP-2 | ISP-2-PE-B | 65124 | 100.2.0.0/16 |

## 2. Router ID (Loopback0)

- 형식: AS 번호 끝 3자리를 4번 반복(`65111` → `111.111.111.111`). Loopback0 `/32`와 `bgp router-id`에 같은 값 사용.
- AS가 장비마다 달라 값이 모두 고유함.

## 3. eBGP 세션

- ISP당 4세션, 합계 8세션. 마름모 구조의 직접 연결 링크(PE-A–P1, PE-A–P2, PE-B–P1, PE-B–P2) 인터페이스 주소로 세션 구성.
- P1–P2 링크(100.1.0.16/30, 100.2.0.16/30)는 BGP 세션 없이 연결만 유지.
- 모든 세션은 직접 연결 인터페이스 주소를 사용하므로 `ebgp-multihop` 불필요.

## 4. 광고 prefix

- PE 장비가 연결된 사이트의 /16을 `network` 구문으로 광고. 사이트 prefix는 PE의 정적 경로(사이트 라우터 방향)로 라우팅 테이블에 존재.
- P1, P2는 prefix를 광고하지 않고 전달만 수행.

## 5. 타이머와 공통 설정

- `timers bgp 3 9`(keepalive 3초, hold-time 9초). ISP 장애 시 ISP-2 전환 실측의 수렴 시간을 단축하기 위한 값.
- `bgp log-neighbor-changes`, `no auto-summary`, `no synchronization`(해당 시) 적용.
- route-map, prefix-list, 인증은 적용하지 않음(실습 환경).

## 6. 경로 선택과 이중화

- 사이트는 ISP-1과 ISP-2에 각각 연결되며 정적 기본 경로를 OSPF로 광고할 때의 metric(ISP-1 100, ISP-2 200)으로 주/보조 경로 구분(`docs/ospf-design.md` 6절).
- ISP-1 장애 시 IP SLA/track이 정적 기본 경로를 제거하여 ISP-2 경로로 전환. 이 전환 시간이 BGP hold-time 9초의 영향을 받음.
- DMVPN 터널(Private Internet 경유)은 ISP와 독립된 경로이며 `docs/dmvpn-design.md` 참조.
